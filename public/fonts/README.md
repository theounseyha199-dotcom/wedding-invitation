# Khmer OS Muol Light

`KhmerOS_muollight.ttf` is the unmodified Khmer OS Muol Light font, version 1.00 (2007), by Danh Hong. Bundled from the locally installed KhmerOS font distribution.

Copyright 2007 Danh Hong. Licensed under the GNU Lesser General Public License, version 2.1 or (at your option) any later version. See `LICENSE-KhmerOS.txt` for the full license. The font retains its original embedded copyright and license notices.

Upstream project and font sources: https://github.com/KhmerSoftwareInitiative/khmer-unicode-fonts

The font is served locally through Next.js. To replace it, update this file and the `khmerDisplay` registration in `src/app/layout.tsx` if the filename changes.
